# Simple Gamer Profile Website

A simple HTML/CSS/JS gamer profile inspired by the supplied reference layout.

## Customize
- Edit profile text and social URLs in `index.html`.
- Put your own audio file beside `index.html` and name it `music.mp3`.
- Change colors and spacing in `style.css`.

## Deploy
Upload all files to the root of your GitHub repository. Vercel will redeploy automatically after the commit.
