# Modern Profile Website V2

## Features
- Premium dark glassmorphism design
- Animated floating particles and aurora glow
- Responsive desktop/mobile layout
- Social link cards
- Music player
- Admin page
- Profile image upload stored in browser LocalStorage
- Vercel-ready static files

## Local use
Open `index.html`, or use VS Code Live Server.
You can also run:
`python -m http.server 5500`

Then visit `http://localhost:5500`.

## Vercel
Upload the project to GitHub and import the repository into Vercel. Use the default static deployment settings.

## Note
The admin panel is a browser-only demo. Data is saved in LocalStorage, not in a secure shared database. A production admin system needs authentication and a backend.
